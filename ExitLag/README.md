# ExitLag

Projeto independente dentro do repositório `cl-udio`.

Esta pasta não tem relação com o Radar de Feedback da raiz do repositório
(`scripts/`, `site/`, `dados/`, `config/`): não compartilha código, dados nem
workflows. Nenhum workflow em `.github/workflows/` é disparado por mudanças aqui.

## Conteúdo

```
ExitLag/
  index.html  # protótipo "ExitLag Route Analysis" (app desktop 1440×810), página única
  home-jogos.html  # "ExitLag Palco": catálogo de jogos no palco (refletores, ping com e sem ExitLag, ferramentas no menu lateral)
  README.md   # este arquivo
```

`index.html` é autocontido: CSS, JS, ícones e imagens estão embutidos no próprio
arquivo (só as fontes vêm do Google Fonts). Para ver, abra o arquivo no navegador.

Origem: artefato https://claude.ai/artifact/QTbaZUfdVKmmViiYVnsKgF
